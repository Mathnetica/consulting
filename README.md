# Mathnetica

Premium engineering consultancy website for Mathnetica — Data & AI Platform Engineering, AI Architecture, Complex Systems Engineering and Architecture Reviews.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tests

```bash
npm test
```

Vitest covers content integrity, contact validation/action, and key UI components.

## Contact form

Copy `.env.example` to `.env.local` and set `RESEND_API_KEY` to enable email delivery. Without it, enquiries are validated and logged in development.
